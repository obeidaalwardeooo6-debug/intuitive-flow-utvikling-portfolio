# 3. Systemarkitektur

## Innledning

I dette prosjektet har jeg brukt HTML, CSS og JavaScript for å utvikle nettsiden Intuitive Flow.

Jeg har også brukt Netlify til publisering og hosting, og Squarespace til å kjøpe og administrere domenet.

I denne delen forklarer jeg hvordan nettsiden er bygget opp, og hvordan de forskjellige teknologiene fungerer sammen.

## Teknologier jeg har brukt

| Teknologi | Bruksområde |
|---|---|
| HTML | Struktur og innhold på nettsiden |
| CSS | Design, farger, oppsett og responsivt design |
| JavaScript | Interaktive funksjoner og navigasjon |
| Netlify | Hosting, publisering og kontaktskjemaer |
| Squarespace | Kjøp og administrasjon av domenet |

## Hvordan fungerer nettsiden?

Når noen åpner `intuitiveflowet.com`, brukes domenet til å finne riktig nettside.

Nettsiden er publisert hos Netlify. Nettleseren laster inn HTML, CSS og JavaScript.

Disse teknologiene har forskjellige oppgaver:

- **HTML** viser innholdet på siden.
- **CSS** bestemmer hvordan nettsiden ser ut.
- **JavaScript** gjør det mulig å bruke interaktive funksjoner.

Jeg har lært at disse tre teknologiene må fungere sammen for å lage en brukervennlig nettside.

## Filstruktur

Jeg har organisert prosjektet med egne mapper for de forskjellige språkene.

| Mappe eller fil | Funksjon |
|---|---|
| `NO/` | Norske nettsider |
| `EN/` | Engelske nettsider |
| `NL/` | Nederlandske nettsider |
| `style.css` | Hovedfil for design |
| `script.js` | JavaScript-funksjoner |
| `workshop-gallery.js` | Funksjoner for bildegalleriet |
| `bilder/` | Bilder og andre medier |
| `index.html` | Hovedfil i prosjektet |

Denne strukturen gjør det enklere å finne filer og arbeide med de forskjellige delene av nettsiden.

## Nettside med tre språk

Intuitive Flow er tilgjengelig på norsk, engelsk og nederlandsk.

Jeg har brukt egne HTML-sider for hvert språk. Det betyr at jeg må kontrollere innhold, navigasjon og lenker når jeg gjør endringer.

Dette har lært meg hvor viktig det er å ha en ryddig filstruktur.

## Responsive design

Jeg har brukt CSS for å tilpasse nettsiden til forskjellige skjermstørrelser.

Målet er at menyene, tekstene og innholdet skal være enkle å bruke på mobil, nettbrett og PC.

Jeg har også arbeidet med å forbedre oppsettet under utviklingen.

## Kontaktskjema

Nettsiden har kontaktskjemaer som bruker Netlify Forms.

Besøkende kan fylle ut et skjema og sende informasjon gjennom nettsiden.

Netlify håndterer skjemainnsendingen. Derfor trenger jeg ikke å utvikle en egen server for denne funksjonen.

## Domene og publisering

Jeg har brukt Squarespace til å kjøpe og administrere domenet `intuitiveflowet.com`.

Netlify brukes til å publisere og hoste nettsiden.

Gjennom dette har jeg lært forskjellen mellom et domene og webhosting.

## Oppsummering

Gjennom arbeidet har jeg fått bedre forståelse for hvordan en nettside er bygget opp.

Jeg har lært hvordan HTML, CSS og JavaScript samarbeider, hvordan filer organiseres, og hvordan nettsiden kan publiseres på internett.

Jeg ønsker å lære mer om systemarkitektur og hvordan jeg kan lage enda bedre og mer effektive løsninger.
