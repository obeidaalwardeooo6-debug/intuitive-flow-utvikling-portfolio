# Intuitive Flow – Utviklingsprosjekt

## Om prosjektet

Jeg har jobbet med å utvikle nettsiden Intuitive Flow i omtrent seks måneder. Målet mitt har vært å lage en moderne, oversiktlig og brukervennlig nettside som fungerer på både mobil, nettbrett og PC.

Nettsiden er publisert og tilgjengelig på internett.

**Nettside:** https://intuitiveflowet.com/no/

## Teknologier og tjenester jeg har brukt

I dette prosjektet har jeg brukt følgende teknologier og tjenester:

- **HTML:** Jeg brukte HTML for å bygge opp sidene og innholdet på nettsiden.
- **CSS:** Jeg brukte CSS for å lage designet og tilpasse nettsiden til mobil, nettbrett og PC.
- **JavaScript:** Jeg brukte JavaScript for å lage interaktive funksjoner.
- **Netlify:** Jeg brukte Netlify til å publisere og drifte nettsiden, samt håndtere kontaktskjemaer.
- **Squarespace:** Jeg brukte Squarespace til å kjøpe og administrere domenet `intuitiveflowet.com`.

Jeg lærte også mer om hvordan et domene kan administreres hos én leverandør, mens nettsiden er publisert hos en annen.

## Hva inneholder nettsiden?

Nettsiden har blant annet:

- Tre språk: norsk, engelsk og nederlandsk.
- Informasjon om tjenester og workshops.
- Navigasjon mellom forskjellige sider.
- Bildegalleri.
- Kontaktskjemaer.
- Responsivt design for mobil, nettbrett og PC.
